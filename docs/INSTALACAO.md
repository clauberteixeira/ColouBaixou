# Como instalar o ColouBaixô

[← Voltar](../README.md)

Leva uns 2 minutos. Não precisa de senha de administrador.

**Precisa de:** Windows 10 ou 11 (64 bits) e internet.

---

## 1. Baixe o instalador

Entre em **[Releases](https://github.com/clauberteixeira/ColouBaixou/releases/latest)** e clique no arquivo **`ColouBaixou-Setup-….exe`** (cerca de 87 MB), na seção *Assets*.

> Se alguém te passou o instalador por **pendrive**, copie para o computador e pule para o passo 3.

## 2. "O Windows protegeu o computador"

Ao abrir o instalador, o Windows pode mostrar uma tela azul com essa mensagem. **É normal.** Ela aparece para programas novos que não têm uma assinatura digital paga, e o ColouBaixô é gratuito e não tem essa assinatura.

Para continuar:

1. Clique em **Mais informações**.
2. Clique no botão **Executar assim mesmo**.

**Outra forma, se preferir:** clique com o botão direito no instalador → **Propriedades** → marque **Desbloquear** (no rodapé da aba *Geral*) → **OK**. Depois abra o instalador normalmente.

> O navegador (Chrome, Edge) também pode perguntar se você quer manter o arquivo. Escolha **Manter**.

## 3. Instale

1. Escolha se quer o **atalho na área de trabalho** (vem marcado) → **Avançar**.
2. Clique em **Instalar**.
3. Deixe marcado **Abrir o ColouBaixô** → **Concluir**.

O programa fica instalado só para o seu usuário do Windows, em `C:\Users\<você>\AppData\Local\Programs\ColouBaixou`.

## 4. Primeira vez que abrir

Na primeira vez, aparece **"Preparando componentes…"** por alguns segundos. Se o computador precisar, o programa baixa um componente extra (Deno). Isso só acontece uma vez.

Pronto! Agora veja **[como usar](COMO-USAR.md)**.

---

## Atualizar para uma versão nova

**É automático.** Quando sai uma versão nova, o programa mostra no topo *"🎉 Nova versão disponível!"*. Clique em **Atualizar agora** e ele baixa, instala e abre de novo sozinho. Suas configurações e seus vídeos continuam onde estão.

O **motor de download** também se atualiza sozinho sempre que você abre o programa.

> Se preferir, também dá para baixar o instalador novo em [Releases](https://github.com/clauberteixeira/ColouBaixou/releases/latest) e instalar por cima.

## Desinstalar

**Configurações do Windows** → **Aplicativos** → **Aplicativos instalados** → **ColouBaixô** → **Desinstalar**.

Os vídeos e áudios que você baixou **não são apagados**.
